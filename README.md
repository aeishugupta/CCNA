# CCNA Networking Labs

A practical collection of networking labs completed while learning CCNA concepts using Cisco Packet Tracer.

## Topics Covered

- Network Fundamentals
- IPv4 Addressing and Subnetting
- VLANs and Trunking
- Static and Dynamic Routing
- DHCP, DNS and NAT
- Access Control Lists (ACLs)
- Network Security
- Network Troubleshooting

## Repository Structure

Each lab contains relevant Packet Tracer files, network topology screenshots, configurations, and documentation where applicable.

## Tools Used

- Cisco Packet Tracer
- Cisco IOS CLI
- Git and GitHub

## Learning Objectives

- Understand network design and device connectivity.
- Configure routers and switches.
- Practice IP addressing and routing.
- Troubleshoot connectivity issues.
- Document practical networking exercises.
